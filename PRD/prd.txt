# Claude Gemini MCP Integration - Product Requirements Document (for Taskmaster)

## Project Overview

The Claude Gemini MCP Integration is a Model Context Protocol (MCP) server that acts as an **intelligent agent**, bridging Claude-based clients (like Claude Code) with Google's Gemini models. It enables developers to leverage Gemini's powerful features (e.g., 1M+ token context window) directly within their coding environment.

The project is evolving from a simple request-response bridge into an **agentic collaboration system** via the **Agentic Collaboration Protocol (ACP)**. This protocol upgrades communication from plain text to structured JSON, enabling more intelligent, precise, and efficient AI interactions.

## Key Features

### Current Features (Phase 1 - Completed):
1.  **Quick Query (`gemini_quick_query`):** Ask Gemini any development question instantly.
2.  **Code Analysis (`gemini_analyze_code`):** Deep analysis of specific code sections.
3.  **Codebase Analysis (`gemini_codebase_analysis`):** Full project analysis using Gemini's large context window.
4.  **Smart Model Selection:** Automatic model selection (Flash for speed, Pro for depth) with API/CLI fallback.
5.  **Security & Configuration:** Robust input sanitization, path traversal protection, and flexible user-driven configuration.

### Future Features (Phase 2 & 3 - Roadmap):
1.  **Structured AI Data Exchange (ACP):** Upgrade `gemini_analyze_code` to return structured JSON (`AgenticCodePatch`) for direct client action.
2.  **Proactive AI Feedback Loop:** Gemini asynchronously analyzes code changes and offers unsolicited, non-intrusive feedback.

## Architecture

The Gemini MCP server uses a decoupled architecture where one installation serves multiple AI clients and projects. The server acts as an intelligent orchestrator:

```
    [Any MCP Client] <--> [Gemini MCP Server (Python/AsyncIO)] <--> [Gemini API (Primary) / Gemini CLI (Fallback)]
```

**Data Flow Evolution:**
*   **Phase 1 (Current):** Client sends natural language prompt -> Server calls Gemini -> Server returns plain text response.
*   **Phase 2 (Next):** Client sends prompt -> Server calls Gemini (requests structured JSON) -> Server receives `AgenticCodePatch` object -> Server formats object into human-readable markdown -> Server sends formatted message to client.

## Current Implementation

The current implementation includes:
1.  **Core MCP Server (`gemini_mcp_server.py`):** Handles MCP protocol communication.
2.  **Gemini Helper (`gemini_helper.py`):** Provides core functionality for interacting with Gemini models.
3.  **Code Analysis Helpers (`helpers/`):** Modules like `analyze_code.py`, `codebase_analyzer.py`, `markdown_utils.py`, `hybrid_progress.py` for pre-processing, post-processing, and UX.
4.  **Configuration (`config.py`):** Handles hierarchical, user-driven configuration.

## Technical Requirements

1.  Python 3.10+ compatibility.
2.  MCP protocol compliance.
3.  Google Generative AI API integration (with `instructor` library for structured output).
4.  Secure handling of API keys and sensitive information.
5.  Efficient processing of large codebases.
6.  Real-time streaming of results.
7.  Smart fallback mechanisms (API to CLI).
8.  Adherence to defined coding standards (modularity, docstrings, type hinting, clarity).
9.  Comprehensive testing (unit, integration, e2e, security, performance) and linting (black, flake8, isort, mypy).
10. CI/CD pipeline via GitHub Actions for automated quality checks and releases.

## User Experience Requirements

1.  Seamless integration with MCP-compatible clients (IDEs, modern terminals, CLIs).
2.  Fast response times for quick queries.
3.  Comprehensive analysis for complex queries.
4.  Clear, actionable, and helpful messages (especially for structured suggestions).
5.  Intuitive tool interaction (via client-side commands).
6.  Progress indicators for long-running operations.

## Deliverables

1.  Enhanced MCP server implementation with ACP capabilities.
2.  Improved helper modules (e.g., dedicated security helper).
3.  Comprehensive documentation (`PRD_v3.md`, `AI_rules.md`).
4.  Expanded test suite and robust CI/CD.

## Timeline

The enhancements will be implemented in phases, with the Structured AI Data Exchange (ACP) being the highest priority for the immediate future.

## Success Criteria

1.  **Structured Output Reliability:** >99.5% valid, schema-compliant `AgenticCodePatch` objects from Gemini.
2.  **User Action Rate on Suggestions:** >30% user acceptance/action on AI-generated suggestions.
3.  **Performance:** P95 response time <10s for quick queries; complex analysis <120s.
4.  **Quality:** >70% code coverage; high user satisfaction; minimal error rates.
5.  **Adoption:** High installation success rate and increasing daily active users.
