# Claude Gemini MCP Integration - Product Requirements Document

## Project Overview

The Claude Gemini MCP Integration is a lightweight integration that brings Google's Gemini AI capabilities to Claude Code through MCP (Model Context Protocol). This project connects Claude Code (coding assistant) with Google's Gemini AI models, enabling developers to ask Gemini questions about their code, get security reviews, performance suggestions, and architectural advice without leaving their coding environment.

The integration automatically chooses the right AI model for each task: fast responses for quick questions, deeper analysis for complex problems. It leverages Gemini's massive context window (1M+ tokens) to analyze large codebases.

## Key Features

1. **Quick Query** - Ask Gemini any development question instantly
2. **Code Analysis** - Deep analysis with security, performance, and architecture insights
3. **Codebase Analysis** - Full project analysis using Gemini's massive context window
4. **Automated Hooks** - Pre-edit analysis, pre-commit review, and session summaries
5. **20+ Slash Commands** - Simple shortcuts like `/g`, `/analyze`, `/security`
6. **Smart Model Selection** - Flash for speed, Pro for depth, automatic fallback
7. **Real-time Streaming** - Live output with progress indicators

## Architecture

The Gemini MCP server uses a shared architecture where one installation serves multiple AI clients and projects:

```
    Claude Desktop  │  Claude Code  │  Cursor IDE  │  VS Code + Extensions
                    │              │             │
                    └──────────────┼─────────────┘
                                   │
                      ┌─────────────────────────┐
                      │     MCP Protocol        │
                      │   (Tool Requests)       │
                      └─────────────────────────┘
                                   │
                          ┌─────────────────┐
                          │  Gemini MCP     │
                          │    Server       │
                          │ (Python/Shell)  │
                          └─────────────────┘
                                   │
                    ┌───────────────┼───────────────┐
                    │               │               │
          ┌─────────────────┐  ┌─────────────────┐  │
          │  Gemini API     │  │  Gemini CLI     │  │
          │  (Direct HTTP)  │  │  (Shell Command)│  │
          └─────────────────┘  └─────────────────┘  │
                    │               │               │
                    └───────────────┼───────────────┘
                                   │
                      ┌─────────────────────────┐
                      │   Google Gemini AI      │

```

## Current Implementation

The current implementation includes:

1. **Core MCP Server** - `gemini_mcp_server.py` that handles MCP protocol communication
2. **Gemini Helper** - `gemini_helper.py` that provides core functionality for interacting with Gemini models
3. **Code Analysis Helpers** - Various helper modules for code and codebase analysis
4. **Configuration** - Configuration handling for API keys, model selection, etc.
